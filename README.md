## 🚀 Key Features by Task

### 1. Pawzz Care — Practo for Animals
* **24/7 Red Alert SOS Mode:** Panic-friendly single-tap triage filter displaying open ICUs and animal ambulances within a 5km radius.
* **Species-Specific Matching:** Dedicated filters for Dogs, Cats, Birds/Exotics, and Stray Indie Rescues.
* **Pawzz Verified Network:** Badges for verified doctors with VCI credentials, fees, and distance.
* **Dual Acquisition Funnels:** B2B supplier onboarding (`List Your Clinic`) and crowdsourced community hygiene (`Submit a Correction`).
* **Hyperlocal Focus:** Tailored for Pawzz's home ground in Gurgaon (DLF Phase 4, Golf Course Road, Sohna Road, Sector 34).

### 2. Pawzz AI Academy — Course Landing Page
* **Differentiated Value Prop:** "Build & Ship" accelerator model resulting in 4 verifiable portfolio projects instead of passive video certificates.
* **Interactive 4-Week Curriculum:** CSS Grid dynamic roadmap tabs showing weekly milestones and lab exercises.
* **Two-Tier CRO Funnel:** High-intent seat reservation application paired with a zero-friction syllabus lead magnet modal.
* **Risk-Free Reversal:** Explicit 7-day 100% money-back guarantee.

### 3. Autonomous Content Creation System
* **5-Stage Zero-Designer Pipeline:** Telegram voice memo $\rightarrow$ Whisper $\rightarrow$ Claude 3.7 JSON $\rightarrow$ Canva/Bannerbear API $\rightarrow$ Buffer scheduling.
* **Sample Carousel Deliverable:** 7-slide carousel in 4:5 Instagram & LinkedIn aspect ratio with client-side 1-click PNG slide export (powered by HTML2Canvas).
* **Live Prompt Simulator:** Interactive tester for parsing raw thoughts into validated design tokens.
* **Economics:** Reduces turnaround time from 2.5 hours to 90 seconds, saving ~₹40,000/month in designer overhead.
